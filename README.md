# Capital Ride Almanac

[Интерактивный атлас](https://dreddxyz.github.io/capital-ride-almanac/) · [Исследование в Jupyter](analysis.ipynb)

Как меняется утренний пик на выходных? Реальный журнал Capital Bikeshare за 2011–2012 годы позволяет проверить это по часам и типам пользователей. Выберите срез и раскройте таблицу под графиком, чтобы увидеть размер выборки.

## Воспроизведение

Python 3.11. `pip install -r requirements.txt`, затем `python pipeline.py`, `pytest -q`. Для локального сайта: `python -m http.server 8000 -d site`. Ноутбук открывается в Jupyter или выполняется через `jupyter nbconvert --to html --execute analysis.ipynb`.

Polars проверяет уникальность дня и часа и равенство сумм. Pandas формирует группы, SQLite независимо считает годовые итоги. NumPy и SciPy оценивают средние и интервалы (1500 повторов, фиксированные seed). Matplotlib и Seaborn строят тепловую карту. CI исполняет ноутбук и публикует расчёт на GitHub Pages.

Источник: [Hadi Fanaee-T, Bike Sharing, UCI](https://doi.org/10.24432/C5W894), лицензия CC BY 4.0. Хеш загруженного CSV записывается в atlas.json. На графике исторические наблюдения. Неполные часы не заменяются нулями. Интервалы описывают среднее внутри среза; разницы между годами и причинное влияние погоды отдельно не оцениваются.
